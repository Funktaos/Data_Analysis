Модули и функции проекта

main.py
- console = Console(): объект Rich для красивого вывода в консоль.
- print_menu(): выводит главное меню приложения в панели Rich.
- get_rating_filter(): запрашивает возраст ребёнка и возвращает фильтр допустимых рейтингов.
- search_by_keyword_menu(): обрабатывает поиск по ключевому слову, выбор поиска по названию или описанию, фильтр рейтинга, пагинацию и логирование.
- search_by_category_year_menu(): обрабатывает поиск по жанру и годам, показывает жанры, проверяет диапазон, применяет фильтр рейтинга, пагинацию и логирование.
- show_top_queries(): выводит таблицу с 5 самыми популярными запросами.
- show_last_queries(): выводит таблицу с последними 5 уникальными запросами.
- main(): запускает основной цикл меню и вызывает нужную функцию по выбору пользователя.

mysql_connector.py
- get_connection(): создает подключение к MySQL-базе sakila.
- get_all_categories(): получает все жанры из таблицы category.
- get_year_range(): получает минимальный и максимальный год выпуска фильмов.
- search_by_keyword(): ищет фильмы по названию, а по выбору пользователя также по описанию.
- count_by_keyword(): считает общее количество результатов для поиска по ключевому слову.
- search_by_category_and_year(): ищет фильмы по жанру и диапазону годов.
- count_by_category_and_year(): считает общее количество результатов для поиска по жанру и годам.

log_writer.py
- save_search(): сохраняет в MongoDB тип запроса, параметры, количество найденных фильмов и время.

log_stats.py
- _query_to_string(): превращает параметры запроса в понятную строку для вывода.
- get_top_5_queries(): получает 5 самых популярных запросов по частоте.
- get_last_5_queries(): получает последние 5 уникальных запросов по времени.

formatter.py
- _base_table(): создает базовую Rich-таблицу с единым стилем, рамками и линиями.
- format_films(): форматирует найденные фильмы в таблицу Rich.
- format_categories(): форматирует список жанров в таблицу Rich.

config.py
- dbconfig: настройки подключения к MySQL.
- mongo_config: строка подключения к MongoDB.

start_demo.bat
- Запускает приложение в отдельном консольном окне для демонстрации.
